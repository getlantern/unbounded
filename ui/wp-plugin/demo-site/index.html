Unbounded × WordPress

Turn any WordPress site into a volunteer proxy.

The Unbounded plugin drops a single widget onto your site. Visitors who switch it on lend a sliver of their connection to someone behind a firewall — no account, no install, nothing to run on your server.

  1. Launch — a fresh WordPress boots and the plugin activates itself.
  2. Look — the widget is already embedded on the front page.
  3. Configure — open Unbounded in the admin sidebar to change layout, theme, and placement.
  4. Toggle — flip the switch to start relaying traffic for real.
