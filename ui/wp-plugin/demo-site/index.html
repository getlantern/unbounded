Questions

Frequently asked

What is Lantern Action Mode for WordPress?

A free WordPress plugin from Lantern that adds the Action Mode widget to your site. The widget is a switch: a visitor who turns it on lends a small amount of their bandwidth to relay traffic for someone whose government blocks the open internet. Visitors install nothing, and no proxy traffic passes through your server.

How does this live demo work?

The launch button opens WordPress Playground, which runs WordPress compiled to WebAssembly inside your browser. It installs and activates the plugin zip built from the current source, and lands on a page with the widget already embedded. Nothing is installed on a server, and closing the tab throws the whole site away.

How do I install the plugin on my WordPress site?

Install Lantern Action Mode from the WordPress Plugin Directory and activate it. Then open Action Mode in the admin sidebar to pick a layout, theme and location, and choose where the widget appears: tick Display on Homepage or Display on Posts, or edit a page and tick Enable Action Mode on this page. It needs WordPress 5.0 or later and PHP 7.4 or later.

What can I configure?

The layout (banner, panel, floating or simple), the theme (light, dark, or the visitor's system preference), whether it sits at the top or bottom of the page, and where it appears: on chosen pages, on all posts, or on the homepage. Version 1.4.0 adds a "Country to support" setting that preselects a censored country for visitors to help; it takes effect only once Lantern switches that feature on for the network.

What happens in a visitor's browser when they turn it on?

Their browser downloads the WebAssembly proxy engine, around 12 MB, from embed.lantern.io, finds people to help through Lantern's signaling server, and relays their traffic to Lantern's exit servers. Relayed traffic is end-to-end encrypted between the person being helped and their destination, so the volunteering browser cannot read it. Turning the switch off, navigating away or closing the tab stops it.

Does it use my visitors' bandwidth without asking?

No. The switch is off when the page loads, and the proxy engine is not downloaded until a visitor turns it on.

Does Action Mode slow down my site?

The widget bundle is deferred, so it does not block rendering. The proxy engine is only downloaded for visitors who turn the switch on.

Can my visitors get in trouble for volunteering?

Volunteers relay encrypted traffic and are not the exit point, so the traffic does not appear to come from their connection. The widget also warns visitors who appear to be in a censored region that volunteering may not be appropriate for them.

What data does the plugin collect?

Action Mode does not track visitors, set advertising identifiers or collect personal data. The widget sends cookieless usage counts to Plausible, tagged with the hostname of your site, and those counts rank sites on the Action Mode leaderboard. The External services section of the plugin's readme lists each service the widget contacts and when. See Lantern's privacy policy.

Can I host the widget bundle myself?

Yes, with the browsers_unbounded_script_url filter. A self-hosted copy is pinned to whatever build you copied and will eventually fall out of step with the network, so the bundle on embed.lantern.io is the default.

What is the relationship between Action Mode and Unbounded?

Unbounded is Lantern's engine for censorship circumvention through browser-based peer-to-peer proxies. The volunteer product built on it, including this plugin, ships as Lantern Action Mode. The product was called Browsers Unbounded, then Unbounded, and is now Lantern Action Mode.

How is Action Mode different from Tor's Snowflake?

Both descend from the flash proxy idea that Fifield et al. described in 2012: volunteers' browsers act as short-lived proxies for people in censored regions. Snowflake is part of the Tor Project. Action Mode is built on Lantern's Unbounded, and one volunteer can proxy for several users at the same time.

Is the plugin open source?

Yes. It is licensed under the GPL, version 3 or later, and developed in the open in getlantern/unbounded. The plugin is in ui/wp-plugin and the widget it loads is in ui/.

Who makes Lantern Action Mode?

Lantern, run by Brave New Software Project, Inc. If you need to get around censorship yourself, get Lantern.
